# Frans Kurniawan - Full-Stack Developer Portfolio 🚀

Website portofolio profesional, modern, dan interaktif untuk **Frans Kurniawan** (Full-Stack PHP Web Developer).

## ✨ Fitur Unggulan
- **Aesthetic Modern Glassmorphism & Dark Mode**: Dirancang khusus dengan palet warna elegan (Slate, Neon Cyan, Indigo, Violet) dan efek glass blur.
- **Interactive Ambient Particle Background**: Canvas interaktif yang merespons pergerakan mouse.
- **Interactive Terminal & AI-Workflow Showcase**: Menyoroti keunggulan workflow rekayasa perangkat lunak berbasis AI Agent.
- **3D Card Hover Tilt**: Efek perspektif 3D pada setiap kartu skill dan project saat disentuh kursor.
- **1-Click Copy & Quick Contact**: Tombol salin instan untuk email & nomor WhatsApp, serta tautan langsung ke GitHub dan LinkedIn.
- **Print / PDF Friendly**: Teroptimasi untuk dicetak rapi langsung menjadi dokumen PDF resume.

## 🌐 Cara Upload & Pasang Live Demo Gratis ke GitHub Pages

Agar kamu punya link portofolio (contoh: `https://franskur.github.io/portfolio/`) yang bisa kamu bagikan ke recruiter di LinkedIn dan CV:

1. Buat repository baru di [GitHub](https://github.com/new) bernama `portfolio` (Public).
2. Buka terminal di folder project ini, lalu jalankan:
   ```bash
   git init -b main
   git add .
   git commit -m "feat: launch interactive portfolio website"
   git remote add origin https://github.com/franskur/portfolio.git
   git push -u origin main
   ```
3. Buka repository kamu di GitHub -> Masuk ke **Settings** -> **Pages**.
4. Pada bagian **Build and deployment**, pilih Source: **Deploy from a branch**, Branch: `main` / `root`, lalu klik **Save**.
5. Dalam 1-2 menit, website portofolio kamu sudah aktif dan bisa diakses oleh siapa saja di seluruh dunia! 🎉
